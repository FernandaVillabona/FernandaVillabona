Soy **Ingeniera Ambiental** de la Universidad El Bosque y **estudiante de Ingeniería de Sistemas**. Desarrollo aplicaciones web con **Angular y TypeScript** en el frontend, y **Node.js y Express** en el backend.

- 🧩 Trabajo con componentización, programación reactiva (RxJS) y arquitectura por features.
- 🧪 Me importa la calidad: pruebas con Jest, Supertest y Jasmine/Karma, y CI/CD con GitHub Actions.
- ♿ Construyo interfaces responsive y accesibles (WCAG).
- 🤝 Experiencia en equipos ágiles con Scrum, junto a diseño, QA y producto.
- 🌎 Español nativo · Inglés B2.
